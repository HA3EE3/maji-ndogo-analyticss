## The Business Problem
My project involved using Python to analyse agricultural data for the Ministry of Agriculture in Maji Ndogo, with the goal of identifying problems in the data and helping improve decision-making.

## The Tech Stack
I used core Python to work with agricultural data, apply logical conditions, organise information using data structures, and validate records. This project allowed me to use Python's built-in features to solve data problems without relying on external libraries.
